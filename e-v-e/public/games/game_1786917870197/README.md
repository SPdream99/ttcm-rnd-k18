# 🎮 ĐẠI CHIẾN TRÙM HƯ KHÔNG (MARATHON QUIZ BOSS SLAYER)

Trò chơi giáo dục hành động tương tác tích hợp chuẩn **E-V-E Game Engine SDK v2.0**.

---

## 🌟 CƠ CHẾ CHƠI (GAMEPLAY & GIMMICKS)

1. **Lựa chọn Vũ khí Gimmick**:
   - ⚔️ **Thanh Kiếm Diệt Thần**: Tăng thêm **+40 Sát Thương** và nhân **2x Điểm Số** cho mỗi câu trả lời đúng.
   - 🪄 **Trượng Phép Thời Gian**: Cộng thêm **+1.5 Giây** vào đồng hồ đếm ngược marathon mỗi khi trả lời đúng.
2. **Giai đoạn Marathon 10 Giây**:
   - Trả lời liên tục các câu hỏi được xáo trộn ngẫu nhiên từ khóa học (hoặc ngân hàng câu hỏi lập trình dự phòng).
   - Sử dụng chuột hoặc phím số `1`, `2`, `3`, `4` để chọn nhanh đáp án.
   - Tích lũy sát thương cực đại trước khi hết thời gian!
3. **Giai đoạn Tổng Tấn Công**:
   - Xả toàn bộ sát thương tích lũy làm sụt thanh máu **1000 HP** của Trùm Hư Không.
4. **Giai đoạn Né Đòn Phản Công (Dodge QTE)**:
   - Trùm sẽ tung đòn phản công hủy diệt!
   - Người chơi phải bấm đúng phím mũi tên (`⬆️`, `⬇️`, `⬅️`, `➡️` hoặc `W`, `A`, `S`, `D` / nút trên màn hình cảm ứng) trong **1.8 giây**.
   - **Né thành công**: Tiếp tục đợt Marathon tiếp theo để hạ Boss.
   - **Bấm sai / trượt thời gian**: Bị trùm hạ gục ngay lập tức (Game Over).

## 📦 HƯỚNG DẪN TEST UPLOAD LÊN HỆ THỐNG E-V-E

1. Nén toàn bộ các file bên trong thư mục này thành file `.zip` (hoặc sử dụng file `boss_battle_quiz.zip` đã được tạo sẵn).
2. Mở hệ thống **E-V-E** -> Tab **Giảng Viên (Teacher)** -> **Upload Center**.
3. Chọn Tab **"Tab 3: Nộp Trò Chơi Mới (.zip)"**.
4. Điền thông tin:
   - **Tên trò chơi**: `Đại Chiến Trùm Hư Không (Boss Slayer Marathon)`
   - **Mô tả**: Trò chơi trắc nghiệm tốc độ đánh trùm với cơ chế chọn vũ khí gimmick và phản xạ né đòn.
   - **Chọn file .zip**: Chọn file `boss_battle_quiz.zip`.
   - **Bật tùy chọn**: `Yêu cầu dữ liệu câu hỏi từ Course (need_extra_data)`.
5. Bấm nút **Gửi Game** để hoàn tất!
